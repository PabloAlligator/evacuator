# Безопасность

## Реализовано

- пароли хешируются Argon2id;
- токены сессий генерируются криптографически стойко и хранятся в базе только в SHA-256 виде;
- cookie: `HttpOnly`, `SameSite=Strict`, в production — `Secure`;
- срок сессии ограничен 30 днями;
- CSRF-токен связан с конкретной сессией;
- изменяющие запросы проверяют `Origin`/`Referer`;
- API и CRM запрещены кэшированию и индексации;
- отдельная строгая CSP для `/control`;
- rate limit на вход и API;
- ограничения размера JSON/form body;
- серверная проверка типов, сумм, дат, телефонов и длины строк;
- нормализованный поиск без прямой подстановки SQL;
- Prisma-запросы предотвращают SQL-инъекции;
- централизованные ошибки не раскрывают stack trace клиенту;
- журналируются вход, выход и изменения бизнес-сущностей;
- SQLite, `.env` и резервные копии исключены из Git;
- зависимости зафиксированы lock-файлом.

## Перед запуском

- заменить `SESSION_SECRET` случайным значением длиной минимум 64 символа;
- установить `NODE_ENV=production`, `APP_ORIGIN=https://evakuator19.ru`, `TRUST_PROXY=1`;
- выставить права `600` на `.env` и файл базы;
- включить HTTPS и редирект с HTTP;
- убедиться, что Nginx проксирует запросы только на приложение;
- выполнить `npm audit --omit=dev` и `npm test`;
- создать первую резервную копию и проверить восстановление на отдельной копии проекта.

## Не хранить в архиве или Git

- `.env`;
- `prisma/*.db` и связанные journal/WAL-файлы;
- содержимое `backups/`;
- `node_modules/`;
- логи PM2/Nginx;
- реальные экспортированные CSV с клиентскими данными.
